CORVUS UI

Goal:
Build the local mobile interface for CORVUS.

Principles:
- Match the approved dark raven/slate/gold design direction.
- Mobile-first.
- Lightweight.
- Local-first.
- UI never executes arbitrary shell commands.
- CORVUS API remains the controlled boundary.
- Existing CORVUS core remains isolated.

Initial navigation:
- Chat
- Library
- Study
- Tools
- Development
- Settings

Phase 1:
Static UI shell and navigation prototype.
